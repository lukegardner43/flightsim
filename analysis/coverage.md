Those two numbers are both true and they are not the same measurement. The first

most of Great Britain by area actually is. Cities are close to finished; everywhere
else is not.

## How to read this

- **Missing** counts OS footprints that no OpenStreetMap building overlaps. It is not
  "OS has more polygons than OSM": OS draws a terrace of eight houses as one block and
  OSM often draws all eight, so counts alone would be nonsense in both directions. Each
  footprint is matched to the other dataset by position before anything is counted.
- **OSM-only** is the honest other half. Some of it is new build finished after the OS
  release; some is sheds and canopies OS does not survey. It is not error on OSM's part,
  and this audit does not treat it as such.
- **House-sized** is footprint area between 50 and 400 m², which is a dwelling nearly
  every time. It is the closest this data comes to counting missing houses, and it will
  undercount flats — one block of flats is one large footprint, not forty houses.
- OS OpenMap Local is Great Britain only, so Northern Ireland is not in this sample.
